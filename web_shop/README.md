# 商城

在仓库根目录执行 `npm ci`，然后执行 `npm run build:shop`。
开发服务：`npm run dev:shop`。后端默认连接 `http://127.0.0.1:8000`，
可通过本目录的 `.env.local` 中的 `DEV_API_TARGET` 调整。
共享组件和工具位于 `../web_common`。

Material Icons 的 4 个字体文件来自 `material-design-icons` 3.0.1，原样保存在
`src/assets/fonts/material-icons`，Apache 2.0 许可证也保留在该目录。
